Простое консольное приложение для работы с заметками, написанное на **чистом Node.js**.  
Приложение позволяет создавать, просматривать, редактировать и удалять заметки прямо из терминала.  
Данные сохраняются локально в JSON-файле.

Используемые технологии

- **Node.js**
- Встроенные модули Node.js:
  - `fs` — работа с файлами
  - `readline` — ввод и вывод в консоли
